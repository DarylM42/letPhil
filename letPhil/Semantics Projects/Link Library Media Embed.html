Quick Tips

  • Use clear descriptive text that explains the destination or action
  • Keep link text concise but meaningful on its own
  • Avoid vague phrases like "click here" or "read more"
  • Ensure each link's purpose is clear even when read out of context
  • Indicate if a link opens a file type or performs a specific action

Descriptive links help accessibility by giving readers and screen-reader users clear self-contained information about the link's destination or action.
